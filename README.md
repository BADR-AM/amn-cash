# AMN Cash — نظام إدارة ومتابعة معاملات وأرباح فودافون كاش 📱💰

نظام مكتبي محلي متكامل (Windows Desktop / Electron + React + Tailwind + SQLite) متصل بتطبيق أندرويد لالتقاط رسائل SMS الصادرة والواردة لمحفظة **فودافون كاش**، وفرزها آلياً، وحساب الرسوم والأرباح الصافية فورياً بدون الاعتماد على أي خوادم سحابية خارجية (Offline-First).

---

## ✨ المميزات الرئيسية للنظام

1. **لوحة تحكم تفاعلية (Dashboard):**
   - متابعة حية لـ: إجمالي الوارد، إجمالي المسحوبات، إجمالي المصاريف، وصافي الأرباح.
   - ملخص أرباح الخدمة الفوري: (رسوم الخدمة − مصاريف السحب = صافي الربح).
   - مخطط دائري لتوزيع المعاملات (وارد / مسحوبات / أخرى).
   - جدول آخر المعاملات المسجلة مع تحديث فوري بدون إعادة تحميل الصفحة (Realtime SSE).

2. **سجل المعاملات والحسابات المالية:**
   - تصفية متقدمة (الكل / وارد فقط / سحب فقط).
   - بحث فوري برقم هاتف العميل، كود المعاملة، أو المبلغ.
   - إمكانية تسجيل المعاملات يدوياً أو استعراض نص رسالة الـ SMS الأصلية.

3. **حاسبة الرسوم والمصاريف (Fee & Profit Engine):**
   - حاسبة تفاعلية للمبالغ لحساب العمولة وصافي الربح المتوقع قبل التنفيذ.
   - تخصيص وحفظ نسب الخدمة (الافتراضي: 50 جنيه رسوم خدمة لكل 1000 ج، 10 جنيه تكلفة سحبنا من الماكينة، 40 جنيه صافي ربح).
   - حساب دقيق بوحدة القروش لتفادي أخطاء التقريب البرمجية.

4. **التقارير المالية المجمعة:**
   - استخراج تقارير لفترة زمنية مخصصة (من / إلى).
   - تصدير فوري لملف **Excel (CSV)** متوافق مع كافة برامج الجداول.
   - إمكانية طباعة التقرير مباشرة.

5. **الأجهزة والاتصال (Android Pairing):**
   - توليد **كود QR** لربط هاتف الأندرويد بضغطة زر عبر شبكة الـ Wi-Fi المحلية.
   - عرض حالة اتصال الهاتف، عنوان الـ IP، ووقت آخر مزامنة.

6. **محاكي رسائل SMS مدمج (Built-in Simulator):**
   - أداة اختبار داخلية تتيح تجربة استقبال رسائل تحويل حقيقية أو عمليات سحب أو اختبار حظر رسائل الـ OTP السرية دون الحاجة لهاتف متصل.

## 🚀 كيفية التشغيل

### الطريقة الأولى: التشغيل بنقرة واحدة
قم بتشغيل الملف:
```cmd
START_AMN_CASH.bat
```
سيقوم هذا الملف ببدء تشغيل الخادم الداخلي (Port 5500) وفتح الواجهة في المتصفح فوراً على `http://localhost:5174`.

### الطريقة الثانية: تشغيل نافذة سطح المكتب (Electron)
```cmd
START_ELECTRON.bat
```

## 🛡️ أمان الخصوصية والبيانات

- **حظر رسائل OTP:** يقوم النظام بحجب واستبعاد أي رسالة تحتوي على رموز تحقق، كود سري، أو PIN، ولا يتم حفظها إطلاقاً في السجلات.
- **تخزين محلي 100%:** كافة المعاملات محفوظة في قاعدة بيانات `amn_cash.sqlite` داخل مجلد `data/` على جهازك فقط.
